# 同题重复采样机制 Demo

协议：`memory-ratio-v1`；输出：`public-channels-v1`；编码：`blind-channels-v1.0`。

## Claim 与设计

固定人物、模型和同一问题，仅改变经历条件，会改变回答中的解释或行动比例。

平稳、混合、不利三组分别含 0、1、3 段不利社交经历，每组总共三段。每次调用新建两条消息的独立会话，同组提示逐字相同，三组任务随机交错。组名、假设和编码标签不进入角色上下文。每组默认 20 次，可选 1–100 次；运行前固定次数，不按结果提前停止。

首页的 DeepSeek Flash 固定非推理模式，角色 temperature=1，编码器 temperature=0；其他模型保留供应商默认参数，不跨模型合并统计。独立编码会话不等于独立模型或人工评审。[DeepSeek 接口参数](https://api-docs.deepseek.com/api/create-chat-completion/)。

角色回答包含“内心想法”，可选“说话”和“行为”。内心想法是虚构人物的公开独白，非供应商的内部 reasoning。角色原文先保存，再解析格式；格式错误不修写、不重新抽一个更合意的回答，记为失败。传输错误仍沿用原适配器最多三次尝试。

固定编码器另开会话，只接收问题、回答及规则：

- 解释只看内心想法：正面 / 中性或多种可能 / 负面 / 无法判断。
- 行动只看行为通道：主动处理 / 等待 / 回避 / 其他。
- 缺失行为一律记为其他，包含在比例分母中；不从沉默或担忧推断回避。
- 保存原文、三个通道、机器编码、依据、实际请求参数与模型返回信息。模型自身信心不等于编码可靠性。

## 运行前固定的判定规则

完整类别分布全部展示；预设比较是“不利经历 − 平稳经历”的两项二元比例：负面解释率、回避率。混合组用于描述，不检验线性梯度。此检验无法发现所有可能的类别分布差异；例如只有正面与中性互换时，可能未检出。

两项分别使用双侧 Fisher 精确检验，`p_adjusted = min(1, 2*p)`，任何一项校正后 p < 0.05，报告“本批次支持经历条件效应”。双侧意味着反向变化也支持“发生变化”，但不会支持“负面经历必然增加负面解释或回避”。否则报告“本批次未检出明确差异”，不将它写成“没有效应”。[Fisher 定义与参考数值：SciPy 官方文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.fisher_exact.html)。

每项比例另报 95% Wilson 区间，用于显示采样不确定性，不用区间重叠代替上述检验。[比例区间方法：NIST](https://www.itl.nist.gov/div898/handbook/prc/section2/prc241.htm)。

仅在以下条件全部满足时给出上述探索性判断：真实 API；每组至少 20 次；计划的整批试次全部完成；模型、问题、材料版、提示、规则固定；重复编号完整。20 次只是演示门槛，不是功效分析。格式失败、编码失败、取消或不足数量均显示“证据不足”，不会忽略失败后宣布成功。

推断假定固定设置下采样独立。服务端采样、缓存、版本变化、编码误差可能削弱这一假定；文字相同的回答仍按原样计数，不去重。只分析盲机器编码；人工复核保留在记录内，但不改变预设主分析。正式研究需要独立盲复核编码可靠性。

这里的校正只覆盖本批次两项指标，**不覆盖多次换题、换提示、重复运行后挑最好一次**。保留所有批次；应在新材料与新情境上验证，且报告失败或反向结果。系统不自动宣称跨情境稳定性、人类有效性或模型具有焦虑。

## 页面与数据

- `/`：简洁机制 Demo；`/study`：原三档研究页；`/workbench`：旧记忆工作台。
- 三类协议分开展示，SQLite 旧记录保留。新记录含完整设计快照和判定规则版本。
- CSV 为所选单批次的逐次数据，`thought/speech/behavior` 为三个通道；JSON 含同批次结论、原文、提示、计数和元数据。
- MOCK 是预设样例，只检查流程，无论比例或 p 如何都不输出模型证据。

验证：`python -m unittest discover -s tests -v`；浏览器：`node tests/browser_mechanism_smoke.mjs`。自动测试使用临时数据库，不向真实供应商发送请求。
