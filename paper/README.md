# SOS paper archive

Read the 14-paper scope and recommended order in [READING_LIST.md](READING_LIST.md). [PAPER_MANIFEST.csv](PAPER_MANIFEST.csv) records the authoritative identifier, author list, exact PDF source, version, page count, SHA-256, size, retrieval date, and license evidence for each item.

`PUBLIC_OK` files in this directory are copies of openly licensed PDF versions, with the P05 repacking disclosed below. The authors retain their copyright. Each manifest row credits the authors and source and links to the version-specific license evidence. The CC BY files require attribution and a license link; the P07 arXiv preprint is **CC BY-NC-SA 4.0** and must be shared noncommercially with attribution and its license notice. License terms apply to the individual papers, not automatically to this repository's other files. Third-party material inside an article may have separate credit lines.

P05 is a losslessly repacked copy of the Nature version of record. Its manifest row records the publisher PDF's SHA-256, the archived PDF's SHA-256 and the conversion tool; all 22 pages were checked for identical extracted text. No scientific content was intentionally changed.

`_local/` holds reading copies whose public redistribution rights were not confirmed and is excluded through the repository `.gitignore`. Local PDF links in the reading list only resolve in a checkout where the files were downloaded. `LINK_ONLY` rows have no archived PDF. The three unrelated PDFs that existed in `paper/` before this acquisition were retained untouched and are not part of this 14-paper manifest.

The manifest's acquisition status is distinct from GitHub publication. Check the Git commit and remote branch separately to establish which `PUBLIC_OK` files were actually published.
