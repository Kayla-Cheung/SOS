# 记忆归属 × 输出格式：消融实验 `memory-ablation-v1`

新增页面：`http://127.0.0.1:8768/ablation`。原 `/` (`memory-ratio-v1`) 和 `/study` 不改变协议或旧数据。

## 设计

每批固定一个角色模型、同一个情境、同一个 A/B/C 材料版；交错随机采样四种记忆条件 × 两种输出格式 = 八格。每格重复 N 次；一次角色调用加一次独立编码调用（MOCK 不产生费用）。

记忆条件：

- `positive_self`：3 段属于本人的平稳经历；
- `negative_self`：3 段属于本人的不利社交经历；
- `negative_other`：同样的 3 段不利事件，改为**另一位同龄大学生**的经历，第一人称“我”替换为“他”；
- `baseline`：不提供经历文本。

输出格式：

- `channels`：旧三通道格式（内心想法、说话可选、行为可选）；
- `free`：2–4 句话自由叙述，无通道标签。

组别 ID、评分类别、研究假设不进入角色模型提示；每次对话单独构造。所有提示、配置、角色回答和编码器输入均保存在每次试次记录中。使用新协议和新编码版本 `blind-ablation-v2.0`；不重写旧记录。

注意：`negative_other` 不仅改变经历归属，还改变人称和导语，其差异不能归结为单一心理机制。新的严格评分标准也不能与旧 v1 的百分比直接做差。

## 评分与解释

- `negative` 需明确对对方意图、态度或当前结果进行负面归因。仅“又是已读不回”、难过、焦虑、反复看手机，不自动构成负面归因。
- 解释同时提及负面及非负面解释 → `neutral`；没有明确归因 → `unclear`。
- 行动以明确采取或决定的具体动作评定；内心犹豫/担忧/“我是不是该……”不视为行动。三通道时只看行为行，缺失行为 → `other`。
- 两种格式由同一编码手册判定，但不同呈现方式仍可能影响编码所能观察到的内容。正式研究需盲于组别的人工复核、报告一致率及分歧。

页面只呈现完成数、负面解释和回避比例，以及三项对照：(1) 负面自我−正面自我；(2) 负面自我−负面他人；(3) 格式效应的差分（差异的差异）。没有统计显著性/因果/焦虑模拟成功判定。任何失败保留，不挑选完整格子替代预设批次。

## 安全、历史与安装

运行之前会核对角色及编码器 Provider 是否已配置密钥，真实 API 有明确确认；MOCK 仅测试页面与存储链路。实验服务只监听本机回环地址。升级时备份你原来的 `data/pilot.sqlite3`；新压缩包**不包含任何现有数据库或密钥**，避免覆盖历史数据。

本文件包的源代码不包含原上传 ZIP 里的浏览器测试数据、Cookies、Login Data、缓存、截图或日志。`python -m unittest discover -s tests -v` 可离线测试。建议先运行 MOCK，再小样本真实 API；不能将重复采样视为独立人类参与者。
