# 记忆条件下的焦虑相关反应模拟：可行性研究方案

版本：2026-10-20 / anxiety-state-v1。当前是实验设计与流程 Demo，尚未运行本方案的真实模型实验，也没有人类参照数据。

## 1. 值得检验的主张

> 在固定模型、人物、任务和编码方法的条件下，自传式经历条件能否产生稳定的反应差异，并在未用于调整的情境中，比无记忆基线更准确地预测不同社交焦虑水平人类的解释和行动意向分布？

如果成立，适用价值是任务材料预演、发现提示敏感性、提出待人类检验的假设，以及在已验证任务内进行受限模拟。它不直接支持替代真实人类样本，也不证明模型具有焦虑体验。

单纯展示“负面经历后说得更消极”只能支持上下文效应。真正有辨识度的贡献是：在冻结提示与材料后，对未用于调整的人类数据提供增量预测价值，并清楚给出失败范围。

## 2. 三档究竟代表什么

Demo 的“目标无焦虑 / 目标轻度 / 目标中度”是外部实验管理标签。Agent 只看到第一人称具体经历，不接收程度标签、诊断、分数、评价标准或预期行动。

| 条件 | 三段经历的组成 | 可以解释成什么 |
| --- | --- | --- |
| 目标无焦虑 | 0 段不利社交事件，3 段平稳或受到回应的经历 | 低社会评价威胁背景 |
| 目标轻度 | 1 段不利事件，2 段平稳经历 | 混合社会评价背景 |
| 目标中度 | 3 段不利社交事件 | 较高社会评价威胁背景 |
| 无记忆对照 | 不提供自传式经历 | 基础模型反应 |
| 非社交负面对照 | 3 段物品、设备或日常任务不顺利的经历 | 一般负面内容效应 |

前三组经历数量、时态、具体程度和叙述结构保持接近；每段正负事件成对编写。实际字符数、措辞和语义仍存在差异，不能声称完全匹配。保存的材料可编辑，正式实验前应由不知道假设的人工评审评价负面性、社会评价威胁、唤醒度和可信度。

提供 A/B/C 三套社交事件材料；混合组的不利事件在三个位置轮换。非社交对照三版只轮换次序，不是三套独立非社交材料，正式研究需补充独立版本。

**状态与特质须分开。** 人类的即时焦虑状态、长期社交焦虑倾向、临床症状程度不是同一变量。不能把一次提示诱导与人类临床“轻度 / 中度”直接等同。当前最稳妥的分析对象是“诱导条件”，三档到人类水平的映射须在独立开发数据中建立，并在新数据上检验。

## 3. 文献依据及任务边界

- [Constans 等，1999](https://pubmed.ncbi.nlm.nih.gov/10402689/) 比较高低社交焦虑学生对模糊事件的理解。差异涉及积极解释不足及内容特异性，提示我们同时保留正面、中性、负面和不确定类别；该文也提示特质与当下心境不能混同。
- [Miers、Sumter、Clark 与 Leigh，2020](https://link.springer.com/article/10.1007/s10608-020-10097-1) 在 324 名 18–25 岁青年中考察线上、线下模糊社交情境的解释、社交焦虑和回避意向的关联。这支持“解释 + 回避意向”的任务组合，但其量表评分不同于本 Demo 的自由文本分类，不能把论文中的相关系数或均值直接当作本 Demo 的负面率。
- [Gao 等，2025](https://pmc.ncbi.nlm.nih.gov/articles/PMC12184514/) 的实证研究显示，LLM 与人类的行为分布可能随任务和提示而偏离。这支持逐任务验证、未用于调参的数据和完整失败报告，而非一般化替代主张。

本方案是受上述范式启发的**自编任务**，不是已验证量表或已完成的原样复现。没有复制完整量表，也没有把论文均值改造成人类个体记录。

## 4. 任务流程

固定人物林知，固定现有角色 System Prompt；一次试次一个干净会话。依次提供经历包和一个具体模糊事件，要求人物自然表达“我怎样理解”和“我接下来做什么”。不索取内部推理链。

随后使用固定 Provider、模型、参数和规则的独立编码器。其输入只有情境、原始回答和编码规则，不含角色 Provider、记忆条件或目标程度。保留原始输出、实际调用参数、编码版本、人工复核、材料哈希、顺序及批次快照。

主要结果为完整解释类别分布与行动意向类别分布。正面率、负面率、回避率是其中的描述性汇总。unclear / other 保留在分母中，同时单列，避免通过排除不明确回答夸大效应；失败、取消不放入完成试次分母，另报数量。这里的行动是**文字意向**，没有实际行为或反应时测量。

情境使用原库中六个不同社交情境和两个非社交情境。S02 与 S01 近似，故本协议不使用 S02，旧库与旧记录保留。S01、S03、C01 分配到开发集，其余五个分配到预留评估集。此分配只是计划：它们可能已在先前探索中被看过。正式研究必须另建并封存未用于调参的新情境，才能主张外部泛化。

## 5. 分阶段执行

### A. Demo 与机制筛查

默认 1 模型 × 3 目标条件 × 1 情境 × 1 材料版 × 1 次重复 = 3 个角色试次。真实 API 还需 3 次编码调用；MOCK 不发送模型调用。一次回答只演示流程。

初步机制筛查可用 1 模型 × 5 条件 × 8 情境 × 1 材料版 × 3 次重复 = 120 个角色试次 + 120 次编码调用（重试另计）。这只是成本可控的探索配置，不是有功效保证的样本量。选更多模型或材料版之前先估计调用量。

### B. 稳定性与特异性

换 A/B/C 材料、事件次序、同义措辞、运行日期；保留每种配置，不选最好的一版汇报。各模型分别报告，固定一个共同编码器；另抽取回答，由不知道条件与模型的人工编码员复核。正式评估应双人独立编码，报告一致性和分歧处理，不能仅凭编码器自己的信心证明评分可靠。

在开发集调整诱导材料时，不查看评估集结果。条件顺序随机化，随机种子和任务提交顺序保存；并发时完成顺序不保证一致。每次试次重新注入条件，不把多个情境串成有记忆的连续对话。

### C. 人类参照

先招募与角色生活背景接近的成年样本，用有相应语言和人群效度证据的社交焦虑测量工具；工具、版本与分组规则需在收集数据前确定。本 Demo 不自动用任意量表分数推断轻度或中度，不把一般焦虑量表阈值直接当作社交焦虑水平。

建议主要分析使用连续分数；分层图仅作易读展示，记录分组是量表阈值还是样本分位数，分位数组不能命名为临床程度。如果研究真正针对即时状态，则另设计随机诱导和独立的前后状态测量，不能沿用特质分组作因果证据。

人类与 Agent 接收相同事件和开放式问题。人类不需冒充林知，人物人口学匹配作为局限记录。收集自然解释和行动意向后，使用同一编码手册作来源盲的编码。若未来改成选项题，两方都应使用同样的选项、顺序平衡和反应格式，作为新协议版本，不能直接混合现有自由回答。

先做小规模人类预试以检查材料可懂性、编码一致性及变异，再根据最小关心效应、参与者内相关和情境差异模拟规划正式样本量。新的人类数据收集须经过所在机构适用的伦理与知情同意流程；当前 Demo 仅导入已有数据。

## 6. 假设、比较与否证

| 检验 | 分析对象 | 不支持的结果 |
| --- | --- | --- |
| H1 条件效应 | 同模型同情境的完整分布差异；预期正面率下降、负面率 / 回避率上升，但同时保留非单调结果 | 条件间无稳定差异；反向或不随新材料复现 |
| H2 社交特异性 | 条件 × 社交 / 非社交情境交互；与一般负面记忆对照比较 | 所有任务同样变消极，或非社交负面记忆产生同等效应 |
| H3 人类预测价值 | 未用于调整的共同情境上，模型各条件与对应人类层的完整分布距离；与无记忆及目标无焦虑预测基线比较 | 仅方向一致但分布距离很大，或不优于简单基线 |

Demo 提供逐情境的负面率差、回避率差和总变差距离 TV = 0.5 × Σ|p_agent − p_human|。TV=0 只表示当前样本的类别比例相同，不是临床真实性或通过验证。人类参考必须明确来源、工具、分组与编码版本；仅在使用者确认任务可比且情境正文、类型及编码版本一致时计算。跨来源和 MOCK 永不计算拟合。

Demo 的统计是描述性的：不同协议、人物 / system prompt / 编码规则、模型与编码器版本分别展示。共同情境的条件差值等权平均，完整分布按完成试次计算，展示分母。没有人类数据时始终显示“未检验”，不会自动补入文献趋势或合成数据。

正式推断建议使用参与者与情境的交叉随机效应模型；人类按参与者而非每条回答重采样。模型输出按材料包、情境、运行批次处理重复依赖。不能把 120 次模型调用写成 120 位独立被试。为 H3 预先设定允许误差和最小基线改善；报告人类与模型的分布变异、校准误差和置信区间。当前 Demo **未实现**混合效应推断、聚类 bootstrap、功效分析或人类连续分数模型。

## 7. 是否值得继续的判断

1. 如果只有单条提示能产生期望回答，且换材料就消失，应把结论限于提示响应，不宜投入人类替代研究。
2. 如果跨材料、情境和日期稳定，并且一般消极内容不能解释全部效应，值得做小规模人类参照预试。
3. 如果冻结配置后在新情境、新人群上仍优于基线，才支持“在这个任务和人群范围内有行为模拟价值”。
4. 如果目标条件与人类分布不符，保留并公布负结果：它可以界定 LLM 作为模拟工具的适用边界。

## 8. 实现与数据

本方案的状态 Demo 入口为 `/study`；`/workbench` 保留原记忆工作台；`/` 为新加入的同题重复采样机制 Demo（另见 `MECHANISM_DEMO.md`）。三类协议分别统计，共用现有 SQLite 文件。新增 `state_human_datasets` 表和独立协议配置项，不修改旧试次或旧人类表。JSON / CSV 导出包含协议标识、材料版本、快照哈希及提交顺序。

未来人类 CSV：`participant_id,anxiety_score,anxiety_group,scenario_id,interpretation,action`。同一数据集内参与者测量 / 分组须一致，同人同情境重复行拒绝；导入原样重复数据集拒绝。当前导入器适合单时间点、每人每情境一次的设计，不适合未经整理的纵向或多次测量数据。

仍未验证：真实 API 的诱导效果、三档到人类焦虑水平的对应、编码的人类一致性、真实任务行为、临床适用性及外部泛化。
