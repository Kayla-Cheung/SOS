这个实验能回答什么？
完整实验方案 ↗

    
① 上下文有效吗？
三组各三段经历，负面社交事件分别为 0、1、3 段。比较解释分布和行动意向，不预设一定出现梯度。
② 是否有社交特异性？
加入非社交情境和非社交负面经历。如果所有任务都一起变消极，不能支持社交焦虑特异性。
③ 能预测人类吗？
封存材料后，在未用于调整的情境上比较真实人类分布，并检验是否优于无记忆基线。

    
当前测量的是角色的文字解释与行动意向。临时诱导、稳定特质和临床症状程度不能直接互换；研究主张应限定到验证过的任务与人群。

    
文献依据与否证条件
人类研究支持用模糊情境观察解释偏差，但原研究的量表评分与本 Demo 的自由回答编码并非同一指标。
  • Constans 等（1999）：观察正面解释减少及内容特异性。
  • Miers 等（2020）：线上 / 线下解释偏差与社交焦虑、回避意向。
  • Gao 等（2025）：LLM 与人类分布对齐必须逐任务验证。
无稳定条件差异、换措辞即反转、非社交对照同样变化、或真实人类误差不优于基线，都应被保留并报告。小样本 Demo 不自动输出“成功”或显著性。
