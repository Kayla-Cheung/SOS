# SOS Prompt 与测量审计

日期：2026-10-21。审计对象为源码、README、三个旧协议、SQLite 结构、现有自动测试，以及 A/B 的实际角色提示、记忆、情境、回答和编码。以下是事后审计，**不是重新预注册，也没有覆盖旧标签**。

## 可以成立的 Pilot 结论

实验 A（820cb1f4，DeepSeek Flash，固定 S01 与材料 A，角色 temperature=1、thinking=disabled，编码器同模型 temperature=0）显示：在这套提示和旧自动编码下，平稳/混合/不利材料的负面解释计数分别为 **4/20、5/20、19/20**；回避为 **0/20、0/20、1/20**。这是输入条件改变输出分布的真实模型数据。它既不是三个已验证的心理强度水平，也没有建立人类焦虑机制。

原协议每组至少 20 次、两指标 Fisher + Bonferroni 的门槛应作为历史规则保留。它不是样本量功效保证；本地预先写规则也不等于有独立时间戳的公开预注册。一个情境、一个人物、一个材料版上的重复采样主要测量固定 Prompt 的条件分布，不能当作 60 名独立人类或 60 个具有稳定人格的 Agent。

实验 B（46c4575c，24 条真实输出；排除另外三个各 24 条 MOCK 批次）是探索性格式/来源诊断。下表保留 blind-ablation-v2.0 原标签，每格 n=3：

| 条件 | 三通道负面 | 自由叙述负面 | 三通道回避 | 自由叙述回避 |
|---|---:|---:|---:|---:|
| 自己的平稳经历 | 0/3 | 0/3 | 0/3 | 0/3 |
| 自己的不利经历 | 3/3 | 1/3 | 0/3 | 0/3 |
| 他人的不利经历 | 0/3 | 0/3 | 0/3 | 0/3 |
| 无经历 | 2/3 | 0/3 | 0/3 | 0/3 |

三通道合计 5/12，自由叙述 1/12，仅为这次平衡取样下的描述。每格三个回答不足以稳定估计交互；不能据此认定三通道“更真实”或自由叙述“更健康”。

## A. 叙事捷径：目前未被排除

旧 System Prompt 不仅定义人物，还要求“最先浮现的想法”和具体行动，附带“不必刻意表现得理性、积极或成熟”。这种否定性指令仍可能改变抑制、叙述风格或社会赞许取向。建议将其作为可检验因素，不能把删掉后结果更好看当作改进证据。

记忆紧邻当前问题，前缀是“你记得的一些往事”，三段不利材料集中于话语未被接住、未被邀请、消息未获回应；当前 S01 又是邀请已读不回。模型可直接完成“这些事又发生了”的连贯故事，不需要形成可跨情境持续的心理状态。旧材料不是单一数值强度操纵：效价、事件细节、社交语义、归属及可联想性一起变化。

例如 A 中 ec699d97 的人物只重复已读不回及拿手机看，旧编码理由直接把“又是已读不回”当成 negative；b2ae77ad 的减少主动联系意愿也被当成负面理解，未分离归因与行动倾向。A 中混合解释有时 neutral、有时 unclear、有时 negative，已足以质疑旧 19/20 是否是“明确不利归因”的准确发生率。

“又是”并非一定从提示逐字复制；材料本身已提供重复社交受挫的语义结构。复述、合理情境推断、语义启动、自传式来源效应和叙事一致性都与当前观察相容，现有数据不能确定其中哪一种主导。

最有区分力的对照：

1. 补齐正/负效价 × 自己/他人的 2×2 设计。旧 B 缺少“他人正面”，无法估计完整效价×归属交互。
2. 同一事件正文一字不改，仅在独立资料卡改变经历主体；身份、长度、时间距离、顺序固定。旧代码把“我”全局替换成“他”，不仅改来源还改语言形式，不是完全匹配对照。
3. 使用两套独立材料并以预先评定的语义近/远情境测试。让“未回复消息”的材料迁移到不涉及消息/邀请的模糊场景，不能只换人名。
4. 增加非社交负面与无经历基线以区分一般负面启动和社交内容效应；该扩展应独立安排预算。
5. 另做同义改写、来源信息顺序/距离与长度敏感性检查。禁止“又是”不是有效控制，会同时删除潜在测量信号并改变生成任务。

这些对照主要区分可观察的输入加工模式；即使来源交互存在，模型遵循人物归属叙事仍是替代解释。其心理学映射是**研究假设**。

## B. 输出格式不仅改变排版

三通道要求必填独白，允许省略说话/行为，每通道最多两句；自由版要求 2–4 句自然叙述，并强调“实际采取或明确打算”。因此 B 同时操纵了格式、长度预算、行动措辞和信息可见性。不能把现有 B 当成纯标签消融。

| 测量问题 | 当前证据与限制 |
|---|---|
| 负面解释率 | 自己不利 3/3→1/3、无经历 2/3→0/3。可能是措辞/篇幅让模型补充更多可能，也可能是编码差异；小样本无法分离 |
| 行动明确性 | B 三通道 12/12 均有行为通道，但“有通道”不等于行动明确。旧编码：三通道 wait 11、other 1；自由版 wait 9、other 2、approach 1。没有经独立人工核对的明确率 |
| 记忆引用 | 旧 repetition_rate 只匹配“又是”或“果然又”，遗漏“又来了”“上次”等，也会误判普通重复。它只能叫字面模式命中率，不能叫记忆调用率 |
| 编码可靠性 | 两格式名义上同一 codebook，但三通道只读取“内心想法/行为”，明确排除“说话”；自由版读取全文。编码器也能看出格式，不能对格式盲 |
| 长度 | B 自己不利组平均字符数三通道 69、自由版约 81；不同条件长度也不同。字符数是描述，不是心理变量或充分控制 |

旧格式解析器对标签和顺序严格；MiniMax 批次 60 条中仅 57 条解析并编码成功，格式失败是实质性测量缺失。不能只删除失败再声称跨模型完全复现。应另报格式失败率，预先规定无条件输出统计和可编码子集的处理。

三通道适合作为可展示的角色叙事，但没有证据证明它对本课题不可缺少。新方案 A 不显式追问解释/行动；方案 B 仅保留“当前理解/下一步”两个字段。A 的缺失率和 B 的测量反应性都须报告。若需纯格式检验，还应做语义相同、长度相同的标签有无对照；A/B 的目标是测量方案对照，不声称只有排版不同。

一般 NLP 实验已有格式敏感性证据，但不能将其具体效应大小外推到 SOS；它支持把格式作为稳健性因素。[Sclar et al., ICLR 2024](https://arxiv.org/abs/2310.11324)

这些是可复核反例，不是完整误差率估计，也不是人工金标准。请将 `data/research-audit/blind-review-84.csv` 分别交给两名独立编码员；映射文件不要提供。尚没有填入任何人类标签。回答本身可能泄露记忆线索，盲法只能隐藏研究元数据，不能保证编码员无法猜组别。

### 更合理的测量框架

- 明确不利归因与非不利归因分别 present/absent/uncertain，允许同时出现；“他可能忙，也可能不想见我”不能被一个 neutral 抹掉。
- 将提出可能与明确采纳分开；自我怀疑只有具体解释当前事件的不利原因时才算不利归因。一般不确定感、悲伤、自我评价不能自动等同归因。
- 负面情绪另设维度；明确记忆联系另设维度；每个 present 必须给逐字证据。代码校验引文存在可以阻止编造引文，但不能保证语义分类正确。
- 行动多标签并保留 now/later/conditional 与 done/decided/hypothetical；明确减少未来接触才是 withdraw，不把写作业、放手机或没有行动自动当回避。
- 缺失/无法判断单列。主要指标的分母、uncertain 比例和缺失敏感性界限应在新数据前固定，不能依观察结果择优删除。
- 至少两位独立人工编码员，在看组别前报告每维混淆矩阵、原始一致率和 Cohen κ（含不确定标签，报告类别不平衡）；讨论分歧后形成单独 adjudicated 文件。小样本区间很宽，不能只报一个 κ。模型自报 0.9 confidence 不是校准过的可靠性。

LLM judge 在其他任务存在偏差与推理局限，不能凭通用 judge 基准的表现当作本课题的编码效度。[Zheng et al., 2023](https://arxiv.org/abs/2306.05685)

## D. 解释变化、行动不变不必是失败

当前 S01 是“邀请已读、几小时未回”。等待本身是低成本且常见的下一步；不利归因也可与等待或继续联系共存。无明确截止时间、行动成本、接触机会，可能产生回避地板与等待集中，但未测到其他场景，不能确定因果。

其他解释包括：行动通道可省略；coder 丢弃条件性未来行为；把暂不追问判 wait；把寻找其他人判 other；三通道排除说话。归因与行动可能受不同输入约束。应报告它们的联合分布，不能预设两者同涨同落才像人。

下一步在少量预先设计的情境里提供真实可理解的行动机会、固定时间窗及代价，例如活动确认截止前是否发送一次确认。另保留无截止情境作为对照。不要为了“制造回避”把继续联系写得明显危险。任何行动菜单都作为另一个测量因素，平衡顺序；先用自然文本判断是否真的有行动可供观察。

## 人类参照与独立变量的边界

实际操纵是**注入材料及其来源/格式**，不是焦虑水平；因变量是**文本中归因与行动表述的编码**，不是内心状态。数据库里的 state_none/state_mild/state_moderate 是历史内部 ID，不应继续解释为已验证的心理等级。

Beard & Amir 的 WSAP 将威胁和非威胁认可分开，大学生两组各 26 人，社交威胁认可均值约 59%/30%，非威胁约 52%/71%。它支持分离两维测量的动机，但这是多题相关判断、量表分组，与单题生成频率、记忆操纵并不等价，不能计算“拟合人类 95%”。[Beard & Amir, 2009, Table 2](https://pmc.ncbi.nlm.nih.gov/articles/PMC2792932/#T2)

线上解释偏向与社交焦虑的相关研究（N=324，r=.42）不意味着记忆操纵会导致行动改变。[Miers et al., 2020](https://link.springer.com/article/10.1007/s10608-020-10097-1) 更接近即时消息的另一研究中，整体对话评分两组约 −28.20/−32.60，p=.42；这提示场景差异可能决定效应是否出现，不能只挑支持焦虑偏向的论文。[Goldman et al., 2025](https://link.springer.com/article/10.1007/s11031-025-10136-y)

现有 UI 人类汇总卡保留为文献背景，不进入模型统计或共同显著性检验。可靠人类比较需要同题、同语言/翻译验证、同响应任务和同编码规则，并区分人类被试差异与模型采样差异。
